     ** v1.1 (23.10.2026):
          - Checkboxes in lists and tables, such as renderer categories, match the theme.
          - Selected rows no longer show a blue checkbox or a white frame.
          - Option dialogs have a soft line between the page list and the page.
          - The search field and page list of option dialogs keep clear of the edges.
          - Options > Processing shows the theme's icons.

     ** v1.0 (23.10.2026):
          - Sharper icons, each drawn for its exact pixel size on the pixel grid.
          - One line weight for every icon, in toolbars, menus, panels and dialogs.
          - Calmer badges: a small +, - or check mark; delete keeps its red dot.
          - Clearer Identify, SQL, SHP, SpatiaLite, Zoom Full and snapping icons.
          - Fixed distorted icons and lines cut off at the icon edge.
          - Disabled icons and arrows are clearly dimmed.
          - Browser and Layers panels use the same sharp icons as the toolbars.
          - Layers groups and Processing Toolbox groups show a folder icon.
          - Processing and Query History entries show modern algorithm icons.
          - Fixed missing modern icons in the Processing Toolbox on some builds.
          - Selected rows and pages show a white icon, like their text.
          - Icons stay sharp when screens, scaling or the icon size change.
          - Toolbar icons on large desktop monitors match QGIS's own size.
          - Each toolbar shows its name above its buttons.
          - Vertical toolbars show a three-letter name on their handle.
          - Divider lines separate toolbars, and a line runs under each row.
          - Toolbar names use a bolder face that reads well at small sizes.
          - Toolbar names are never cut short, and wide toolbars centre their buttons.
          - Empty toolbars shrink to a sliver instead of an empty box.
          - Premium Dark uses a softer, lighter grey and one soft text colour.
          - Premium Dark has a cleaner green accent.
          - Menus, drop-down lists and tooltips are flat, without a drop shadow.
          - Fields, drop-down lists, spin boxes and buttons share one height.
          - Secondary buttons are tonal, and disabled buttons are outlined.
          - A thin accent focus edge replaces the thick focus ring.
          - Section titles are semibold in sentence case.
          - Dialog page lists have rounded pills and fit all Layer Properties pages.
          - The Labels and Diagrams sub-page lists match the dialog page lists.
          - The Labels tabs have soft separators between them.
          - The selected Options page stays fully highlighted on hover.
          - Unfocused selections keep a faint accent instead of plain grey.
          - Checkboxes, radio buttons and slider knobs are no longer clipped.
          - Checked menu items show an accent check mark.
          - The message bar is a raised card with a stripe in its level's colour.
          - Fields and Actions tables use row lines instead of a grid.
          - Attribute tables have no grid lines and a firm header rule.
          - Drop-down lists open below the field and show all their items.
          - The map canvas has one edge line instead of two.
          - Layers, Browser and Processing rows are rounded, full-width pills.
          - Tabbed panels switch with a segmented control.
          - Code editors use the theme's colours.
          - Numbers in spin boxes and editable lists are centred.
          - Digits are tabular, so changing numbers no longer jitter.
          - UI text is lighter and no longer reads as bold.
          - Compact sizes are chosen automatically on low-density monitors.
          - Collapsible sections keep the modern arrows.
          - Help in dialog button rows is a quiet text button.
          - The Plugins dialog checkboxes keep clear of the list border.
          - Icons are drawn once and shared by every theme.
          - Theme switches no longer redraw any icons.
          - Hover, selection changes and resizing run half as much plugin code.
          - Toolbar names and lines are painted by Qt without plugin code.
          - Large dialogs reopen faster because their icons are remembered.
          - Theme updates rewrite only the files that changed.
          - Upgrading in a running QGIS keeps the theme and its icons.
          - The View menu no longer has the toolbar labels and compact items.
          - Fixed unreadable dark text in the expression builder's Feature picker.
          - Fixed the Studio palette and font staying after a plugin reload.
          - Fixed the status bar message keeping the previous theme's colour.
          - Fixed an outdated stylesheet staying after an update.
          - Fixed the stylesheet staying after disabling the plugin.
          - Fixed one failed background task stopping later builds.
          - Fixed icons left broken after a crash.
          - Fixed icons on the wrong rows after leaving a Studio theme.

     ** v0.9 (18.10.2026):
          - Themes renamed with Light/Dark: Studio Premium Dark, Web Dark,
            Orange Dark, Orange Light (saved choices follow automatically).
          - Brighter Premium green; stronger accents and text where contrast
            was low; theme list in Options sorted alphabetically.
          - About 260 more QGIS icons modernised (Options, Project Properties,
            Advanced Digitizing, Data Source Manager, Browser, layout designer,
            styling panel, Processing Toolbox incl. GDAL tools, Python console,
            script editor and more), incl. drop-down buttons, sub-menus and
            option trees.
          - Lighter, slightly larger icons; simple accent-dot badges.
          - Toolbar name labels on each toolbar handle (View > Studio Toolbar
            Labels to turn off).
          - Larger, more spaced main menu; larger panel toolbar icons; clearer
            panel titles; Browser, Layers and Processing panels share roomier
            rows.
          - Processing Toolbox: folder icons for groups, distinct tool icon.
          - Clearer disabled text and icons in every theme.
          - Faster startup: only the active theme is prepared up front; icons
            are pre-rendered and identified in the background.
          - Faster dialogs, menus and tab switching (lighter icon scan, no
            fingerprinting of symbol previews, cached toolbar labels).
          - Smoother Processing Toolbox and Browser, and theme switching with a
            single repaint.
          - Icons stay modern when plugins (e.g. Processing) are turned on at
            runtime, and in mode buttons such as snapping overlap.
          - Sharp icons on scaled (HiDPI) screens; DB Manager, Oracle and more
            provider icons modernised; dialog page lists fit when collapsed.
          - Stable memory use and theme switching over long sessions.
          - Smaller, faster-loading fonts.
