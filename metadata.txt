changelog=

     ** v0.9 (18.10.2026):
          - Lighter, slightly larger icons; crisper add/remove/check badges.
          - Slightly larger main menu text and larger icons in panel toolbars
            (Browser, Layers, Processing Toolbox...).
          - About 230 more QGIS icons modernised: Options and Project Properties
            pages, Advanced Digitizing, Data Source Manager, Browser, annotation
            tools, layout designer, styling panel, Processing Toolbox and more.
          - Toolbar names shown as small labels on each toolbar's handle
            (View > Studio Toolbar Labels to turn them off).
          - Icons in drop-down buttons, sub-menus and option trees now follow
            the theme too.
          - Faster startup: only the active theme is prepared at startup,
            the others are built in the background.
          - Faster opening of dialogs and windows (cheaper icon scan).
          - Icons are pre-rendered in the background without slowing the UI.
          - Stable memory use and theme-switch speed over long sessions.
          - Smaller, faster-loading fonts.

     ** v0.8 (15.10.2026):
          - New modern icon set and Inter font.
          - Redesigned, cleaner and faster themes.
          - Themed message bar.
          - Faster startup and icon drawing; native, faster lists and tables.
          - Faster theme switching without stale colours.
          - Studio Pro renamed to Studio Pro Light.
          - Fixed Studio Pro Light being treated as a dark theme (#3).
          - Fixed unreadable selected table cells in dark themes.

     ** v0.7 (26.07.2026):
          - New Studio Light Orange theme (Kartoza brand colours, WCAG-checked contrast).
          - New Studio QGIS Light theme (QGIS brand style guide colours).
          - Light Studio themes now force a light Qt colour scheme even when
            the desktop is in dark mode (dark themes force dark likewise).

     ** v0.6 (13.07.2026):
          - Fixed marker symbol grid layout in the Layer Styling panel.

     ** v0.5 (08.07.2026):
          - Fixed Layer Styling layout width and icon alignment.
          - Improved panel scrollbar width and hover color.
          - Updated icon.
     
     ** v0.4 (21.06.2026):
          - Fixed operator button icons.
          - Fixed layer panel extension button icon.
          - Fixed symbol preview widget internal borders.
          - Fixed debugging panel vertical menu width.
          - Updated icon.

     ** v0.3 (25.05.2026):
          - Updated checkbox appearance.
          - Filled dropdown list white margins.

     ** v0.2 (19.05.2026):
          - Fixed arrow visibility.
          - Fixed progress bar appearance.

     ** v0.1 (18.05.2026):
          - Initial release.
