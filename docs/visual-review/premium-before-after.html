The ranked list

Ordered by how much of QGIS each change improves and how visible it is. Each one is buildable with the plugin's existing tools: stylesheet tokens and rules, the palette, or its item delegates.

How to read the frames. Both frames are drawn from the same markup; only design tokens and a few rules scoped to the proposal differ, so every difference you see is one of the ten changes. The map, data and layer styling are identical in both because they belong to the project, not the theme.

Implementation notes. Most changes are token or rule edits in style.qss and premium/variables.qss. Three need small plugin code: #4 sets the page list's icon size (qproperty-iconSize also works), #5 gives section titles small capitals with QFont (Qt stylesheets have no text-transform), and #8 replaces the fixed yellow QGIS gives every provider field row (#fcff4f, translucent) through the plugin's row delegate.
